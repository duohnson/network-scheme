CLASE 8 : CAP 10 : LAN SECURITY CONCEPTS

AMENAZAS DE SEGURIDAD EN LA LAN:

1. ATAQUES DE RECONOCIMIENTO: RECOPILAR INFORMACION DE LA RED.
2. ATAQUES DE ACCESO: EXPLOTAR VULNERABILIDADES PARA ACCEDER.
3. ATAQUES DE DENEGACION DE SERVICIO (DoS): SATURAR RECURSOS.

------------------------------------------------
TIPOS DE ATAQUES EN CAPA 2:

1. MAC ADDRESS TABLE OVERFLOW / MAC FLOODING:
	INUNDAR LA TABLA MAC DEL SWITCH CON DIRECCIONES FALSAS.
	EL SWITCH EMPIEZA A HACER FLOODING DE TODO EL TRAFICO.
	HERRAMIENTA: MACOF

2. VLAN HOPPING:
	SALTAR DE UNA VLAN A OTRA SIN AUTORIZACION.
	METODOS:
		- SWITCH SPOOFING: EL ATACANTE NEGOCIA TRUNK CON DTP.
		- DOUBLE TAGGING: ENVIAR TRAMAS CON DOBLE ETIQUETA 802.1Q.

3. DHCP ATTACKS:
	- DHCP STARVATION: AGOTAR TODAS LAS IPS DEL POOL.
	- DHCP SPOOFING: SERVIDOR DHCP FALSO QUE ASIGNA GATEWAY FALSO.

4. ARP SPOOFING / ARP POISONING:
	ENVIAR MENSAJES ARP FALSOS PARA ASOCIAR SU MAC CON LA IP DEL GATEWAY.
	RESULTADO: MAN-IN-THE-MIDDLE.

5. CDP/LLDP RECONNAISSANCE:
	OBTENER INFORMACION DE DISPOSITIVOS VECINOS.

------------------------------------------------
MEJORES PRACTICAS DE SEGURIDAD:

1. DESACTIVAR PUERTOS NO UTILIZADOS
	INTER RANGE FAST0/10-24
	SHUTDOWN
	EXIT

2. DESACTIVAR DTP EN PUERTOS DE ACCESO
	SWITCHPORT MODE ACCESS
	SWITCHPORT NONEGOTIATE

3. CAMBIAR VLAN NATIVA (NO USAR VLAN 1)
	SWITCHPORT TRUNK NATIVE VLAN 99

4. DESACTIVAR CDP EN INTERFACES NO NECESARIAS
	NO CDP ENABLE

5. ACTIVAR BPDU GUARD Y PORTFAST
	SPANNING-TREE PORTFAST
	SPANNING-TREE BPDUGUARD ENABLE
