CLASE 6 : CAP 7 : DHCP : DYNAMIC HOST CONFIGURATION PROTOCOL

SINTAXIS:

IP DHCP POOL (NOMBRE)
NETWORK (RED) (MASCARA)
DEFAULT-ROUTER (IP GATEWAY)
DNS-SERVER (IP DNS)
DOMAIN-NAME (NOMBRE DE DOMINIO)
LEASE (TIEMPO / INFINITE)
EXIT
IP DHCP EXCLUDED-ADDRESS (IP / RANGO DE IPS)
ASIGNA IP DINAMICA Y ALEATOREAMENTE

EJEMPLO:
IP DHCP POOL CCNA
NETWORK 192.168.0.0 255.255.255.0
DEFAULT-ROUTER 192.168.0.1
DNS-SERVER 8.8.8.8
DOMAIN-NAME DHCP.EMPRESA.COM
EXIT
IP DHCP EXCLUDED-ADDRESS 192.168.0.1 192.168.0.5

----------------------------------------------------------------------------
PAQUETES DE DHCP:
DISCOVER : BROADCAST
OFFER    : UNICAST
REQUEST  : BROADCAST  
ACKNOWLEDGE: UNICAST
---------------------- 24 HORAS
REQUEST  (REN): UNICAST  
ACKNOWLEDGE: UNICAST

-----------------------------------------------------------------------------

CONFIGURAR ROUTER COMO AGENTE DE RETRANSMISION:

INTER FAST0/0  (LO MAS CERCA AL CLIENTE)
IP HELPER-ADDRESS (IP DEL SERVER)
IPV6 DHCP RELAY DESTINATION (IP SERVER) (INT SALIDA)
EXIT

-----------------------------------------------------------------------------
CONFIGURAR ROUTER COMO CLIENTE DE DHCP:

INTER GI0/0
IP ADDRESS DHCP
NO SHUTDOWN
EXIT

SIN ESTADO: SIN CONTROL SIN ARRENDAMIENTO SIN RENOVACION, AL AZAR
CON ESTADO: CON CONTROL, CON ARRENDAMIENTO CON RENOVACION, (PROTOCOLO DHCP)


MANERAS DE CONTESTAR UN RA:

1. SLAAC: STATELESS ADDRESS AUTO CONFIGURATION

PARAMETROS BASICOS: 	IPV6
			PREFIX
			GATEWAY

CONFIGURACION:

INTER GI0/0
IPV6 ADDRESS 2001:DB8:aCAD:1::1/64
NO SHUTDOWN
EXIT
IPV6 UNICAST-ROUTING

--------------------------------------------------------------

2. DHCP SIN ESTADO: 
	(SLAAC)						(DHCP)
PARAMETROS BASICOS: 	IPV6			PARAMETROS AVANZADOS: DNS
			PREFIX
			GATEWAY

CONFIGURACION:

INTER GI0/0
IPV6 ADDRESS 2001:DB8:aCAD:1::1/64
NO SHUTDOWN
IPV6 DHCP SERVER CCNA
IPV6 ND OTHER-CONFIG-FLAG
EXIT
IPV6 UNICAST-ROUTING

IPV6 DHCP POOL CCNA
DNS-SERVER 2001:DB8:aCAD:8:8888::8
EXIT

			PREFIX
