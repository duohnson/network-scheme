RUTAS ESTATICAS VS PROTOCOLOS DE ENRUTAMIENTO

RUTAS ESTATICAS: (NO ENVIAS ACTUALIZACIONES DE ENRUTAMIENTO)
	
	VENTAJAS: SON MAS SEGURAS
		  CONSUMEN MENOS RECURSOS

	DESVENTAJAS: MAYOR SOBRECARGA ADMINISTRATIVA
		     NO SON ESCALABLES

PROTOCOLOS DE ENRUTAMIENTO DINAMICO:(SI ENVIAS ACTUALIZACIONES DE ENRUTAMIENTO)

	VENTAJAS: MENOR SOBRECARGA ADMINISTRATIVA
		  SON ESCALABLES

	DESVENTAJAS: MENOS SEGUROS
		     CONSUMEN MAS RECURSOS

---------------------------------------------------------------------------------------------------

CLASIFICACION DE LOS PROTOCOLOS DE ENRUTAMIENTO:

IGP: INTERNAL GATEWAY PROTOCOL (DENTRO DE UN MISMO AS (SISTEMA AUTONOMO))

	VECTOR DISTANCIA: MAS LENTO / MENOS RECURSOS
	
CLASSFULL	RIPV1		IGRP
CLASSLESS	RIPV2		EIGRP
	
IPV6		RIPnG		EIGRP PARA IPV6

	ESTADO ENLACE: MAS RAPIDOS / MAS RECURSOS

IPV4		OSPFV2		IS-IS
IPV6		OSPFV3		IS-IS PARA IPV6


EGP: EXTERNAL GATEWAY PROTOCOL (COMUNICACION ENTRE AS)

	VECTOR RUTA:	
		BGP-4
		BGP-MP

COMPONENTES DE UN PROTOCOLO DE ENRUTAMIENTO:
1. ESTRUCTURA DE DATOS : LO QUE QUIERO PUBLICAR?
2. MENSAJES DEL PROTOCOLO: COMO LO VOY A PUBLICAR?
3. ALGORITMO : CORAZON DEL PROTOCOLO : DETERMINA LAS MEJORES RUTAS EN BASE A LAS MENORES METRICAS.


BALANCEO DE CARGA: SE CUMPLE CUANDO 2 O MAS RUTAS TIENEN LA MISMA METRICA.
