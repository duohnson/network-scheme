CAP 15: RUTAS ESTATICAS

Ruta estática estándar : PARA LLEGAR A UNA RED ESPECIFICA.

SINTAXIS
	IPV4:	IP ROUTE (RED) (MASCARA) (INT.SALIDA / SIG SALTO) (AD)
	
	EJEMPLO:IP ROUTE 192.168.0.0 255.255.255.0 SER0/0/0		(PUNTO A PUNTO)
		IP ROUTE 192.168.0.0 255.255.255.0 10.0.0.2		(MULTIPUNTO)
		IP ROUTE 192.168.0.0 255.255.255.0 SER0/0/0 10.0.0.2	(HUB / COMPLETAMENTE ESPECIFICADA)

	IPV6:	IPV6 ROUTE (RED / PREFIX) (INT SALIDA / SIG SALTO) (AD)

	EJEMPLO:IPV6 ROUTE 2001:DB8:ACAD:1::/64 SER0/0/0		(PUNTO A PUNTO)
		IPV6 ROUTE 2001:DB8:ACAD:1::/64 FE80::2			(MULTIPUNTO)
		IPV6 ROUTE 2001:DB8:ACAD:1::/64 SER0/0/0 FE80::2	(HUB / COMPLETAMENTE ESPECIFICADA)


Ruta estática predeterminada : COINCIDEN CON TODOS LOS PAQUETE
OTROS NOMBRES: RUTA POR DEFECTO / GATEWAY DE ULTIMO RECURSO / QUAD ZERO / RUTA DE DESCARTE /

	EJEMPLO:
	IPV4:	IP ROUTE 0.0.0.0 0.0.0.0 SER0/0/0

	IPV6:	IPV6 ROUTE ::/0 SER0/0/0
