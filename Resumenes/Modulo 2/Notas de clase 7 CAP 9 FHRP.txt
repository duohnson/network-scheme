CLASE 7 : CAP 9 : FHRP : FIRST HOP REDUNDANCY PROTOCOLS

PROBLEMA: SI EL DEFAULT GATEWAY FALLA, LOS HOSTS PIERDEN CONECTIVIDAD.
SOLUCION: USAR UN GATEWAY VIRTUAL COMPARTIDO ENTRE MULTIPLES ROUTERS.

------------------------------------------------
CONCEPTOS:

ROUTER ACTIVO: EL QUE REENVIA TRAFICO NORMALMENTE.
ROUTER STANDBY: EL QUE ESPERA EN CASO DE FALLO.
IP VIRTUAL: LA IP QUE COMPARTEN AMBOS ROUTERS (ES EL GATEWAY DE LOS HOSTS).
MAC VIRTUAL: LA MAC ASOCIADA A LA IP VIRTUAL.

------------------------------------------------
PROTOCOLOS FHRP:

1. HSRP : HOT STANDBY ROUTER PROTOCOL (CISCO)

	ESTADOS: ACTIVE / STANDBY / LISTEN
	PRIORIDAD POR DEFECTO: 100 (MAYOR = MEJOR)
	PREEMPT: PERMITE QUE EL ROUTER CON MAYOR PRIORIDAD RECUPERE EL ROL ACTIVO.

	CONFIGURACION:
	INTER GI0/0
	STANDBY 1 IP 192.168.1.1
	STANDBY 1 PRIORITY 110
	STANDBY 1 PREEMPT
	EXIT

2. VRRP : VIRTUAL ROUTER REDUNDANCY PROTOCOL (ESTANDAR IEEE)

	ESTADOS: MASTER / BACKUP
	PRIORIDAD POR DEFECTO: 100
	SIMILAR A HSRP PERO ESTANDAR ABIERTO.

	CONFIGURACION:
	INTER GI0/0
	VRRP 1 IP 192.168.1.1
	VRRP 1 PRIORITY 110
	EXIT

3. GLBP : GATEWAY LOAD BALANCING PROTOCOL (CISCO)

	ESTADOS: AVG (ACTIVE VIRTUAL GATEWAY) / AVF (ACTIVE VIRTUAL FORWARDER)
	BALANCEA CARGA ENTRE MULTIPLES ROUTERS.

------------------------------------------------
COMPARACION:

PROTOCOLO	PROPIETARIO	BALANCEO	ESTANDAR
HSRP		CISCO		NO		NO
VRRP		NO		NO		IEEE
GLBP		CISCO		SI		NO

------------------------------------------------
VERIFICACION:

SHOW STANDBY			(HSRP)
SHOW STANDBY BRIEF		(HSRP RESUMIDO)
SHOW VRRP			(VRRP)
SHOW VRRP BRIEF			(VRRP RESUMIDO)
SHOW GLBP			(GLBP)
