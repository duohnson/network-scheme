CLASE 9 : CAP 11 : SWITCH SECURITY CONFIGURATION

PORT SECURITY: LIMITA LAS DIRECCIONES MAC PERMITIDAS EN UN PUERTO.

------------------------------------------------
CONFIGURACION DE PORT SECURITY:

INTER FAST0/1
SWITCHPORT MODE ACCESS
SWITCHPORT PORT-SECURITY
SWITCHPORT PORT-SECURITY MAXIMUM 2
SWITCHPORT PORT-SECURITY MAC-ADDRESS STICKY
SWITCHPORT PORT-SECURITY VIOLATION SHUTDOWN
EXIT

------------------------------------------------
MODOS DE VIOLACION:

MODO		DESCARTE	REGISTRO	APAGAR PUERTO
SHUTDOWN	SI		SI		SI (ERR-DISABLED)
RESTRICT	SI		SI		NO
PROTECT		SI		NO		NO

RECUPERAR PUERTO EN ERR-DISABLED:
INTER FAST0/1
SHUTDOWN
NO SHUTDOWN
EXIT

O AUTOMATICAMENTE:
ERRDISABLE RECOVERY CAUSE PSECURE-VIOLATION
ERRDISABLE RECOVERY INTERVAL 600

------------------------------------------------
DHCP SNOOPING: FILTRA MENSAJES DHCP NO CONFIABLES.

IP DHCP SNOOPING
IP DHCP SNOOPING VLAN 10,20

INTER GI0/1			(HACIA SERVIDOR DHCP O TRUNK)
IP DHCP SNOOPING TRUST
EXIT

INTER RANGE FAST0/1-24		(PUERTOS DE ACCESO)
IP DHCP SNOOPING LIMIT RATE 6
EXIT

------------------------------------------------
DYNAMIC ARP INSPECTION (DAI): VALIDA PAQUETES ARP.

IP ARP INSPECTION VLAN 10,20

INTER GI0/1
IP ARP INSPECTION TRUST
EXIT

------------------------------------------------
IP SOURCE GUARD: PREVIENE IP SPOOFING.

INTER FAST0/1
IP VERIFY SOURCE
EXIT

(REQUIERE DHCP SNOOPING HABILITADO)

------------------------------------------------

SHOW PORT-SECURITY
SHOW PORT-SECURITY INTERFACE FAST0/1
SHOW PORT-SECURITY ADDRESS
SHOW IP DHCP SNOOPING
SHOW IP DHCP SNOOPING BINDING
SHOW IP ARP INSPECTION
