CLASE 3 : CAP 4 : INTER VLAN ROUTING

CONFIGURACION GENERAL DEL SWITCH:

VLAN 10
NAME VLAN10
EXIT

VLAN 20
NAME VLAN20
EXIT

INTER RANGE FAST0/1-5
SW MODE ACCESS
SW ACCESS VLAN 10
EXIT
INTER RANGE FAST0/6-10
SW MODE ACCESS
SW ACCESS VLAN 20
EXIT
INTER RANGE FAST0/20-24
SW MODE TRUNK
EXIT

------------------------------------------------
MANERAS DE ENRUTAR VLANS:

1. ENRUTAMIENTO TRADICIONAL (ANTIGUO)

INTER FAST0/0
IP ADD 192.168.10.1 255.255.255.0
NO SHUTDOWN
EXIT

INTER FAST0/1
IP ADD 192.168.20.1 255.255.255.0
NO SHUTDOWN
EXIT

------------------------------------------------
2. ROUTER ON STICK

INTER FAST0/0
NO SHUTDOWN
EXIT

INTER FAST0/0.10
ENCAPSULATION DOT1Q 10
IP ADD 192.168.10.1 255.255.255.0
EXIT

INTER FAST0/0.20
ENCAPSULATION DOT1Q 10
IP ADD 192.168.20.1 255.255.255.0
EXIT

--------------------------------------------------
CONFIGURACION DE NATIVA:

SWITCH:
INTER RANGE FAST0/20-24
SW MODE TRUNK
SW TRUNK NATIVE VLAN 99
EXIT

ROUTER:
INTER FAST0/0.99
ENCAPSULATION DOT1Q 99 NATIVE
EXIT
